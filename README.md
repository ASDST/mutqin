# متقن — ورد اليوم

موقع ويب بسيط (صفحة واحدة) يعرض **ورد اليوم** من خطة مسار الحفظ في برنامج متقن:
الحفظ، والتكرار، والمراجعة التراكمية، والمراجعة القديمة — بحسب اليوم الحالي بالتقويم الهجري (أم القرى).

## المميزات

- يعرض **ورد اليوم وأمس** تلقائيًا حسب التاريخ.
- **اليوم يبدأ من الساعة ٤ فجرًا** (توقيت الرياض) إلى ٤ فجر اليوم التالي.
- **زر «تجاوز اليوم»** لإيقاف تقدّم الخطة مؤقتًا وقت التوقفات (الاختبارات مثلًا) دون أن يختل حسابك.
- تاريخ ويوم هجري، وأرقام عربية.
- يعمل بدون إنترنت، وكل شيء محفوظ على جهازك فقط (تخزين محلي).
- طابع متقن: الأخضر المزرق والذهبي، مع الشعار، ووضع فاتح/غامق.

## التشغيل

افتح `index.html` مباشرة في المتصفح — الملف مكتفٍ بذاته (الشعار مضمّن بداخله).

لفتحه كـ«موقع» على الجوال يمكن استضافته مجانًا عبر **GitHub Pages**:
`Settings → Pages → Branch: main → /(root)`، ثم افتح الرابط على الجوال و«أضِفه إلى الشاشة الرئيسية».

## البيانات

الخطة الحالية = ١٢٤ يومًا (الحفظ من صفحة ٢٧٣ إلى ٥١٧)، تبدأ الأحد ٢٧ محرّم ١٤٤٨هـ.
لكل يوم صفٌّ واحد فيه: الوجه الأخير للحفظ، وبداية المراجعة التراكمية، وجزء المراجعة القديمة —
وتُشتق منه المهام الأربع تلقائيًا. البيانات في مصفوفة `PLAN` داخل `index.html`.
